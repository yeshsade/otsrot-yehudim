# חבילות 845 הישנות

קובצי ZIP בתיקייה זו נוצרו לפני תיקון מיקומי הלחצנים וגודל הכיתוב שהורה בעל המוצר ב־20.10.2026. הם נשמרים כתוצרים קודמים, ואינם חוברת מעודכנת מאושרת למסירה.

ראו [תיקון הסקיל והחסמים הנותרים](../docs/SKILL7-FIXED-BUTTONS-2026-10-20.md). הסקיל המעודכן אינו מזיז לחצנים כדי לעקוף חפיפה, ועוצר מסירה כשאין מקום מותר.

נוצרו מקומית שתי חוברות מתוקנות שעברו אימות לפי הכלל המאוחר של לחצנים שקופים מעל טקסט. [דוח האימות העדכני](../docs/SKILL7-TRANSPARENT-BUTTONS-2026-10-20.md). קובצי ZIP כאן טרם הוחלפו בהם.

תיקון נוסף לשולחן ערוך נבנה ונבדק מקומית: [דוח כיסוי הלימוד העדכני](../docs/SKILL7-SHULCHAN-VALIDATION-2026-10-20.md). חבילות ZIP הישנות בתיקייה זו אינן כוללות אותו.
