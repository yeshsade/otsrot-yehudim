# כיתוב מותאם בכפתורי המעבר הקיימים — בכל נושאי הלימוד

## הבקשה המחייבת

**להשאיר את אותם כפתורים שקיימים היום ורק לשים עליהם כיתוב מותאם. הכלל חל על כל נושאי הלימוד שיש בהם כפתורי מעבר. נושא שאין בו כפתורים נשאר בלי כפתורים.**

הדוגמאות של הגמרא והמשנה מסבירות את הכלל לכולם. הן אינן בקשה לקישור מהגמרא למשנה, ואינן מגבילות את העדכון לשני הנושאים האלה.

משנים רק את הטקסט. מספר הכפתורים, המיקומים, גדלי השטחים, יעדי הלחיצה וסדר העמודים נשארים כפי שפעלו במקור. אין להוסיף כפתורים, אין להעביר אותם ואין להמציא יעדים.

## כלל הכיתוב

הכיתוב מציין את **הנושא שאליו הכפתור מוביל ואת יום היעד**, במבנה `ל<נושא>-<יום>`. יש להשתמש במקף רגיל `-`.

| נושא בניתוח | דוגמת כיתוב על כפתור קיים שמוביל ליום שלישי |
| --- | --- |
| הדף היומי | `לדף היומי-יום שלישי` |
| נביאים וכתובים | `לנביאים וכתובים-יום שלישי` |
| משנה | `למשניות-יום שלישי` |
| שולחן ערוך | `לשולחן ערוך-יום שלישי` |
| משנה ברורה | `למשנה ברורה-יום שלישי` |
| זוהר | `לזוהר-יום שלישי` |
| ליקוטי מוהר"ן | `לליקוטי מוהר"ן-יום שלישי` |
| ליקוטי הלכות | `לליקוטי הלכות-יום שלישי` |
| ספרי רבינו על פי הסדר | `לספרי רבינו על פי הסדר-יום שלישי` |
| שמות הצדיקים / ספר המידות | `לשמות הצדיקים / ספר המידות-יום שלישי` |
| ליקוטי תפילות | `לליקוטי תפילות-יום שלישי` |

שם היום הוא היום שאליו מגיעים בלחיצה, ולא היום שמוצג בעמוד הנוכחי. `שבת קודש` נשארת בשם הקיים בסקיל. כפתור חזרה קיים לשבוע הקודם מסתיים ב־`-שבוע שעבר`; הקישור ההדדי ממנו ליום ראשון מסתיים ב־`-יום ראשון`.

## הדוגמאות שהמשתמש הבהיר

| נושא ויום בעמוד הנוכחי | כפתור עליון קיים | כפתור תחתון קיים |
| --- | --- | --- |
| גמרא, יום ראשון | `לדף היומי-שבוע שעבר`, אם נמסר עמוד קודם | `לדף היומי-יום שני` |
| משניות, יום ראשון | אין כפתור עליון | `למשניות-יום שני` |
| משניות, יום שני | `למשניות-יום ראשון` | `למשניות-יום שלישי` |
| גמרא, יום שני | `לדף היומי-יום ראשון` | `לדף היומי-יום שלישי` |

אין להוסיף כפתור שבוע קודם בכל יום, קישור מהגמרא למשנה או כפתור עליון למשניות ביום ראשון. אותו כלל כיתוב חל על כל יתר הנושאים בלי לשנות את מבנה הניווט שלהם. נושאים בלי כפתורי מעבר נשארים בלי כפתורי מעבר. תוכן העניינים וכפתורי החזרה אליו נשארים כפי שהיו.

אם הלימוד היומי מתפרס על כמה עמודים, הכפתור העליון נשאר בעמוד הראשון והתחתון באחרון, בדיוק כמו במקור. בגמרא נשמרת ההבחנה בין עמודי הפירוש לעמודי הגמרא: ברצף רגיל הכפתורים בעמודים השני והשלישי; בשישה עמודים עם כפילות מאושרת א/ב בשני ובחמישי; בשמונה עם כפילות מאושרת בשניהם בשני ובשביעי. אין לנחש כפילות.

## ביצוע ובדיקות

מנגנון ההפקה: `days/scripts/add_day_notes.py`. מנגנון תמונות הכיתוב: `days/scripts/toc_template.py`. קובץ בדיקת הגמרא משתמש באותו כלל כיתוב, ושומר את העמודים והקישורים המקוריים שלו.

מהתיקייה הראשית של הסקיל:

```bash
python3 -m unittest discover -s tests -v
```

נדרשים PyMuPDF, Pillow וגופן עברי זמין. הכיתוב מותאם לשטח הקיים של הכפתור; אם חסר גופן מתאים או הטקסט אינו נכנס, יש לעצור במקום להציג כיתוב פגום.

הבדיקות משתמשות בקובצי PDF מלאכותיים ובתשובות הרגרסיה מסוכות 838 ובראשית 840. קובץ `tests/fixtures/original-navigation.json` נוצר ישירות מהקוד המקורי השמור בגיבוי, לפני התיקון, עם אותם נתוני בדיקה. הבדיקה משווה אליו את כל מספרי העמודים, שטחי הלחיצה ויעדי הקישורים: 138 קישורי מעבר בסוכות ו־140 בבראשית, בדיוק כמו במקור. השוואה זו בודקת גם שלא נוספו כפתורים לנושאים שאין בהם כפתורים.

נבדקים גם הדוגמאות לעיל, הכיתוב לכל נושא, סיבובי 90/270 מעלות, כפילות גמרא, הדדיות לשבוע קודם, חזרת תהילים, 15 יעדי תוכן העניינים לפי נושאים ושימור הניווט לאחר הוספת תיבות וי אמיתיות.

זו בדיקת מנגנון באמצעות PDF מלאכותי. קובצי החוברות המקוריים אינם זמינים בענן; בדיקת העימוד והמרווח מהטקסט בחוברת אמיתית תיעשה עם קובצי המקור לפני מסירתה. אין לעקוף את בדיקות הקבלה האחרות של הסקיל.
