# מסך הגדרות Android — 2026-10-13

## המימוש

מסך Android מקורי ב־ReaderSettingsActivity, בעיצוב ב שנבחר: כותרת צבעונית מעוגלת, כרטיסים, סמלים מלאים ו־Noto Sans Hebrew. יש מצב יום ולילה וכיוון עברית RTL/אנגלית LTR. השם PDF Reader Dev והסמל הגנרי הם זמניים לגרסת פיתוח; שם המוצר הסופי פתוח.

שש בחירות מחוברות להעדפות אמיתיות: כיוון דפדוף, פתיחה חוזרת, זמן מסך, נעילת סיבוב לאפליקציה בלבד, יום/לילה ושפה. בחירת מצב מסמך נשמרת בהעדפת תצוגת PDF, בלי לשנות את צבעי הקובץ עצמו. שליטת „סימון רצוף” מוצגת מושבתת: מנגנון העט והסימון הרצוף המתוכנן טרם מומש. אין מצב „רקע חם”. הרשימה וקורא המסמכים עצמם עדיין מהממשק המיובא, ותפריטי ההגדרות המתקדמות אינם ממשק עברי מאושר.

המקור היחיד לנוסחים הוא design/settings-copy.approved.json, גרסה 4 שאושרה בתשובה „כרגע כן”. scripts/sync_android_settings_copy.py בודק את החתימה ומייצר assets/settings-copy.json ואת מזהי הפריטים. שני התיאורים הריקים נשארים מוסתרים. קובץ הטיוטה משמש לעריכות עתידיות בלבד. אין שינוי במילים המאושרות.

באנדרואיד נעשה שימוש בגופנים קבועים במשקלים 400/550/600, המופקים מהגופן המשתנה של הדוגמה באמצעות scripts/generate_android_fonts.py ו־fontTools 4.62.0. כך הגופן עובד גם ב־Android 6 ואינו נופל למשקל ברירת המחדל 100 של הגופן המשתנה. המקור, החתימות ורישיון OFL נשמרו.

## מסך דולק וסיבוב

ReaderWindowPolicy מופעל דרך מחזור החיים של הפעילויות. „דולק עד יציאה מהאפליקציה” חל על כל חלונות האפליקציה הפעילים, כולל ההגדרות; הדגל משוחרר כשהפעילות עוברת לרקע או נסגרת. „כמוגדר במערכת” אינו מחזיק את המסך. ברירת המחדל MORE מחזיקה אותו לעשר דקות מאז אינטראקציה בקורא ואז משחררת למדיניות הטלפון. התוספת המדויקת לזמן המערכת וצריכת הסוללה דורשות מדידה במכשיר אמיתי; בדיקת גבולות המדיניות אינה מדידת זמן כיבוי פיזית.

נעילת סיבוב נשמרת לפי הכיוון הנוכחי וחלה בתוך האפליקציה בלבד. אין כתיבה להגדרות הסיבוב של הטלפון. השפה מתחילה לפי הטלפון, עם אפשרות עברית/אנגלית; התרגום המאושר חל כעת על מסך ההגדרות החדש.

## תיקון גשר PDF

בדיקת Android מצאה שאחרי שמירת תיבות מסומנות, FPDFAnnot_IsChecked דיווח false בפתיחה חוזרת אף שה־PDF הכיל Yes. תוקן רישום העמוד לסביבת הטפסים לפני שאילתת שדה/עריכה, פעם אחת לעמוד, עם סגירה תואמת. התיקון בגשר mainJNILib.cpp; אינו משנה את מיקום התיבות או מוסיף תיבות לחוברות. בדיקת Android מכסה שש תיבות סינתטיות בשלושה עמודים וסיבובים שונים, שמירה, פתיחה חוזרת וביטול.

## בנייה ובדיקה חוזרת

משורש המאגר, עם JDK21/SDK36/NDK28.2.13676358 ובספריות native מוכנות:

```sh
python android-reader/scripts/sync_android_settings_copy.py
python android-reader/scripts/gradle.py :app:testDebugUnitTest :app:assembleDebug :app:assembleDebugAndroidTest --console=plain --max-workers=2
```

להפקת הגופנים מחדש: להתקין fontTools==4.62.0 ולהריץ python android-reader/scripts/generate_android_fonts.py. להוראות הספריות וגרסאות הכלים: ANDROID_BUILD_STATUS.md ו־android/SETUP.md. שינוי C++ דורש קישור מחדש לשתי הארכיטקטורות באמצעות ndk-build APP_ABI='arm64-v8a x86_64' מתיקיית PdfiumAndroid/src/main/jni לפני Gradle.

בדיקת Android: להתקין app-debug.apk ו־app-debug-androidTest.apk באמולטור API35 x86_64 ולהריץ:

```sh
adb shell am instrument -w com.yeshsade.otzarot.reader.test/com.gitlab.mudlej.MjPdfReader.NativeSettingsProbe
```

יש לקרוא את פלט הבדיקה, ולא להסתפק בקוד יציאה של adb: כישלון Instrumentation עשוי להחזיר קוד תהליך אפס. ההצלחה המצופה היא Passed 6 native checks. הבדיקה משנה העדפות באפליקציית הבדיקה ומייצרת תמונות וקובצי PDF בתיקיית files הפרטית.
