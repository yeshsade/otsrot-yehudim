# אוצרות יהודים — מפת גרסאות הסקיל

במאגר נשמרים שלושה צילומים מלאים ונפרדים של `lefi-yamim-6`.
כל צילום נמצא בענף משלו תחת `skill/lefi-yamim-6`; אין למזג תיקיות
ידנית ואין להתקין מתוך קובצי ה־ZIP ההיסטוריים.

## הגרסאות

| ענף | שם | מקור | מצב |
|---|---|---|---|
| `6` | 6 | הבסיס המשותף המתוקן שהועלה לפני יום כיפור | בסיס היסטורי שמור |
| `MOM` | MOM | המחשב של אמא | הגרסה הפעילה והזהה כעת ל־`main` |
| `HEIDER` | HEIDER | מחשב החיידר אחרי סוכות | מועמדת לבדיקת בנייה |

## מה פעיל עכשיו

`main` נשאר על `MOM` עד שהמשתמש יבדוק בפועל שהענף `HEIDER` בונה חוברת
תקינה. אין למזג את `HEIDER` ל־`main` אוטומטית.

## בדיקה והתקנה

1. בוחרים במפורש את הענף שרוצים לבדוק.
2. מעתיקים את `skill/lefi-yamim-6` בשלמותו לתיקיית סקילים זמנית או למחשב
   הבדיקה; לא מערבבים אותו עם התקנה קיימת.
3. בונים חוברת ממקורות נקיים ובודקים עמודים, קישורים, כפילויות ותיבות V.
4. רק לאחר אישור מפורש מחליטים איזו גרסה תהפוך ל־`main`.

## חומרים היסטוריים

- `versions/` וקובץ ה־ZIP שבשורש הם ארכיונים בלבד.
- `notes/pending-other-computer-changes.md` מתעד את ההבדלים בין `MOM`
  ל־`HEIDER` ואת ההחלטות שעדיין דורשות בדיקה.
- `claude/android-reader` הוא פרויקט קורא PDF נפרד ואינו גרסת סקיל.
